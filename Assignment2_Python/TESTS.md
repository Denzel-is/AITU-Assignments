# Test results

Re-run on 2026-10-06. Actual output below was captured from standard output; every run exited with code 0 and empty standard error.

## Test 1
General scenario

Input:
```text
CONFIG 0
ADD 101 3 SW
ADD 202 5 HW
TRIAGE
TRIAGE
FIND 101
SERVE
SERVE
END
```

Expected:
```text
ADDED 101 P=33
ADDED 202 P=51
TRIAGED 101 P=33
TRIAGED 202 P=51
FOUND 101 READY P=33
SERVED 202
SERVED 101
```

Actual:
```text
ADDED 101 P=33
ADDED 202 P=51
TRIAGED 101 P=33
TRIAGED 202 P=51
FOUND 101 READY P=33
SERVED 202
SERVED 101
```
